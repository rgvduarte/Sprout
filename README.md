# Sprout

Mercado B2B fechado de commodities agroalimentares (azeite, água, café): desintermediação produtiva, captura da margem do embalador e financiamento de lotes com liquidação a 18 meses.

Nome de trabalho. Este repositório reúne:

| Pasta | Conteúdo |
|---|---|
| `webapp/` | Interface da plataforma (React + Vite), com dados de demonstração |
| `docs/fonte/` | Transcrição do documento-fonte (plano estratégico de 13/10) |
| `docs/research/` | Base factual: mercado, regulação, pagamentos, risco e concorrência, com fontes |
| `docs/resumo/` | Resumo executivo em PDF |
| `docs/business-plan/` | Business plan em PDF e modelo financeiro em Excel |

Site publicado (GitHub Pages): https://rgvduarte.github.io/Sprout/
